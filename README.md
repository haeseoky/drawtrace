# 🎮 DrawTrace

> 그림 추리 & 캐주얼 게임 서비스

## 🌐 서비스 URL
- **메인:** https://game.nutalk.co.kr

## 📋 소개
그림을 추리하고, 색깔을 맞추고, 기억력을 테스트하는 캐주얼 모바일 게임 서비스입니다.

## ✨ 주요 기능
- 🎨 **그림 추리 게임** — AI 생성 그림 맞추기
- 🌈 **색깔 맞추기** — 정확한 색상 찾기
- 🧠 **기억력 게임** — 패턴 기억 테스트
- 📱 **모바일 최적화** — 터치 인터페이스

## 🛠 기술 스택
- **Frontend:** Vue 3 + Vite
- **Canvas:** HTML5 Canvas API
- **배포:** Cloudflare Pages
- **디자인:** hub-design-guide (밝은 테마)

## 📂 구조
```
src/
├── components/     # 게임 컴포넌트
├── data/           # 게임 데이터
├── lib/            # 유틸리티
├── views/          # 페이지 뷰
└── assets/         # 이미지, 사운드
```

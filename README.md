# 🎮 DrawTrace

> 그림 추리 & 캐주얼 게임 서비스

## 🌐 서비스 URL
- **메인:** https://game.nutalk.co.kr

## 📋 소개
모양을 따라 그리고, 반응 속도를 테스트하고, 기억력을 단련하는 5종 미니게임 허브입니다. 누구나 즐길 수 있는 캐주얼 브라우저 게임!

## ✨ 주요 기능
- ✏️ **모양 따라그리기** — 보이는 모양을 정확하게 따라 그리기
- ⚡ **반응 속도 테스트** — 초록색 신호에 빠르게 반응
- 🧠 **기억력 카드** — 같은 그림 짝 맞추기
- 🎨 **컬러 매치** — 글자 색상과 일치하는 버튼 찾기
- 🧱 **핑퐁 벽돌깨기** — 벽돌을 깨고 아이템 수집
- 🏆 **전체 랭킹** — 모든 게임 통합 랭킹 시스템
- 📱 **모바일 최적화** — 터치 인터페이스, PWA 지원

## 🛠 기술 스택
- **Frontend:** Vue 3 + Vite
- **Canvas:** HTML5 Canvas API
- **배포:** Cloudflare Pages
- **디자인:** hub-design-guide (밝은 테마)

## 📂 구조
```
src/
├── components/     # 게임 컴포넌트
├── data/           # 게임 데이터
├── lib/            # 유틸리티
├── views/          # 페이지 뷰
└── assets/         # 이미지, 사운드
```
